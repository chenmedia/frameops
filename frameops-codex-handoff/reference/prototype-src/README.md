# FrameOps Radix UI mockups

Interactive product mockups for four core FrameOps views:

- Event operations dashboard
- Coverage command center
- Staffing and freelancer recommendations
- Mobile field run sheet

## Run locally

```bash
pnpm install
pnpm dev
```

The prototype uses React, Vite, Radix Themes, and Radix Icons. Mock data is intentionally realistic but contains no live client information.

## Visual direction

The interface uses a “transit dispatch” model: crew are routes, stages are stops, priority moments are junctions, and conflicts read like service disruptions. It keeps the planning layer calm and information-dense while making the mobile field view highly focused.
