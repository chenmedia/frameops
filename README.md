# FrameOps

FrameOps is a Next.js application starter with a ready-to-use UI foundation.

## Stack

- Next.js 16 with the App Router and TypeScript
- Tailwind CSS 4
- shadcn/ui conventions and CLI configuration
- Radix UI primitives

## Development

Install dependencies and start the development server:

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Add another shadcn/ui component with:

```bash
npx shadcn@latest add <component>
```

## Validation

```bash
npm run lint
npm run build
```
